Only 26 elements are monoisotopic, having exactly one stable isotope; these have an odd atomic number of protons, with the exception of beryllium-9 which has an odd number of neutrons. The mean number of stable isotopes for the 80 stable elements is 3.1 stable isotopes per element. The largest number of stable isotopes for a single element is 10 (for tin, element 50). Elements with atomic numbers 1 through 82 each have at least one stable isotope (except for technetium, element 43 and promethium, element 61, which have no stable isotopes).
